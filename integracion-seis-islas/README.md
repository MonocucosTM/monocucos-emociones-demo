# MONOCUCOS — Integración de las seis islas (prueba)

Rama independiente de trabajo para la navegación de «Todos tenemos un lugar».

## Acuerdos aprobados

- Las seis islas permanecen visibles en un mismo mapa; exploración libre.
- Al pasar el cursor sobre una isla aparece una tarjeta flotante junto a ella, sin taparla. En pantallas táctiles, la tarjeta se abre al tocarla.
- Cada tarjeta incluye nombre, breve invitación narrativa y botón «Explorar la isla».
- El botón lleva directamente al primer momento de la historia, sin pantalla introductoria adicional.
- Transición suave y estética artesanal; mapa visible mientras se lee.
- Las ilustraciones originales y las historias aprobadas no se modifican.
- Regreso al mapa para continuar explorando.

## Texto aprobado — La Isla del Agua

> En esta isla, el agua encuentra muchos caminos. Algunos nadan, otros se arrastran y otros descubren maneras de llegar.
>
> ¿Te gustaría conocerla?
